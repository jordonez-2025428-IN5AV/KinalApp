# Kinal App

**Este es un Proyecto desarrollado con 
SpringBoot para la gestión de un sistema web**

## Tecnologías 
* **JDK 17**
* **SpringBoot 3.5.1**
* **MySQL**
* **Maven**
## Requisitos Previos

* **JDK 17 o versiones superiores**
* **Maven**
* **Instancia de MySQL**
* **Editor de Texto (Visual Studio Code / IntelliJ Idea)**

## Instalación y Ejecución

* **Clonar el repositorio**
* **Ejecutar la aplicación desde IntelliJ idea**
